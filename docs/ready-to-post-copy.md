# Ready-to-post copy — Distribution Plan, Channel 1

Pulled straight from `distribution-plan.md`'s cheapest/fastest channel: communities where
Nigerian visa applicants already are. Same honest "not immigration advice" framing already used
inside the product itself — nothing here oversells it.

Post these as a genuine, useful answer inside an existing thread/question where you can, rather
than as a cold standalone post — that's what the distribution plan recommends, and it reads far
less like an ad.

## Priority order

1. **Nairaland (Travel section) + Facebook/WhatsApp groups first.** This is where the actual
   audience is concentrated, the copy below is already tuned for it, and there's essentially no
   downside — worst case, a post gets ignored.
2. **Reddit second, and more selectively.** The audience is thinner and self-promotion rules vary
   sub to sub (some ban it outright, some are fine with a disclosed link in a relevant reply).
   Check each subreddit's rules before posting, reply into a real "which documents do I need /
   am I ready" thread rather than posting cold, and always disclose you built it — that's both
   the honest thing to do and what keeps Reddit from treating it as spam.

Space posts out over a few days rather than firing all of them at once, and stay around to answer
any replies/questions — that's what makes it read as a real person helping, not a drive-by ad.
